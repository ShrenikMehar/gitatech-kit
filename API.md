## episode.py  (Driver runtime: import episode as E)

Constants: `EP`, `TL`, `L`, `ORDER`, `DUR`, `FPS`, `EMPH_T`, `GAPS`, `EB`, `SYN`

- `E.keep_punct_in_emphasis(cap)`: Move punctuation that directly follows an *emphasised* span inside it ('*so,*' not '*so*,'), so captions don't split it off. Works on properly paired spans only: odd chunks after splitting on '*' are emphasised.
- `E.setup(page_at=None, emph=None)`: page_at: {line_id: audio word index where caption page 2 starts} (lines whose cap has a '|'). emph: {line_id: [word indices]} that get a nod + brow lift in close-ups and standing busts.
- `E.w(lid, i)`: Start time of audio word i in line lid (indices as printed by voices.py).
- `E.we(lid, i)`
- `E.cut(a, b)`: A shot boundary between line a and the next line b.
- `E.plate(t, a, b, f=0.12)`: 1 between a and b, with f-second fades: for things that appear and leave.
- `E.lerp_cam(a, b, k)`: Blend two flat 2D camera tuples (scale, focus_x, focus_y, screen_y), or any equal-length number tuples. For isometric iso.Cam keyframes use gt.cam_lerp instead.
- `E.shot_at(t, shots)`: shots: [(start, kind, key)] sorted. Returns ((start, kind, key), next_start).
- `E.bust(key, mouth_i=0, blink=0, brow_on=False, gaze=None)`: Rendered bust image for an expression key in gt.BASE (krishna, krishna_smile, krishna_knowing, arjun_panic/worried/ curious/relief/frustrated/sheepish/determined). LRU-cached. Add new keys to gt.BASE/MOUTHS (and chars.EXPR) first.
- `E.who_of(key)`
- `E.speaking(t, who)`: (is this character speaking at t, mouth 0/1/2).
- `E.life(t, t0, t1, seed=0.0)`: Head motion for a bust shown from t0 to t1: nods + brow lifts on emphasised words, slow sway, gaze away in pauses. Returns rot (deg), dy (px), brow_on, gaze.
- `E.standing_bust(c, key, t, t0, x, y_bottom, s, t1=None, flip=False)`: A character inside the world (talking, blinking, nodding), bottom-centre at (x, y_bottom), scale s. Call from a world's scene() so depth order is right. Busts face right by default; flip=True mirrors.
- `E.blur_backdrop(c, draw_scene, t, tint=0.45)`: Half-res render of draw_scene(canvas, t), blurred, as a close-up background.
- `E.plain_backdrop(c, top='#1a2440', bottom='#070a16')`
- `E.closeup(c, key, t, t0, t1, backdrop=None, glow_col=None, py=1250, scale=0.86)`: Bust close-up from t0 to t1. backdrop(c, t) draws the background (e.g. lambda c, t: E.blur_backdrop(c, scene, t)); default is a plain gradient. Draw cards or pills after calling this.
- `E.verse_card(c, t, t_in, lines, ref, y0=250, a_out=1.0)`: Small shloka card: Devanagari lines (shaped via raqm) + 'GITA x.yy'. Slides in at t_in. Tiro Devanagari has no Latin punctuation: use '।' inside lines, write the ref in Latin.
- `E.hud(c, t, label, value, col, t_change, a=1.0, sub='', plate=False)`: Top-right label + big value that pops when it changes at t_change. Keep the HUD area (y < ~190) free otherwise. plate=True draws a dark rounded backing, needed over bright scenes (daytime walls, white kitchens).
- `E.code_line(c, toks, x, y, a=1.0, size=32, nchars=None)`: One line of syntax-coloured mono code. toks: [(text, kind)] with kind in SYN. nchars types it out. Returns (x_end, chars_drawn). JetBrains Mono here is a latin subset: no arrows, use '›'.
- `E.panel(c, x0, y0, x1, y1, a, title=None, border=None)`: Dark rounded panel (code editor / terminal / browser). title adds a window bar with traffic lights.
- `E.pill(c, x, y, txt, col, a, size=20, k=1.0)`: Small rounded label centred at (x, y); k < 1 pops it in.
- `E.caption_line(t)`
- `E.finish_frame(c, t, shots=None, flash=True, top_shade=True, end_fade=True)`: Vignette, top shade, a soft flash at each shot cut, karaoke caption, fade to black at the end. Call last in frame(t), after the HUD.
- `E.run(frame, cues)`: frame(t) -> skia.Image; cues() -> [(t, name, gain_db)] with names whoosh, swell, pop, hit, glitch, tick, bowl, riser, chime, train (see mix.py).
