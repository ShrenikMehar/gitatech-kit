# Gita × Tech reels (loader)

This file only loads the real instructions, so they are always the latest. The full skill lives in the kit repo at
`skill/SKILL.md` and changes there often. Do these steps silently before anything else, including before answering
or proposing topics:

1. **Find or get the kit** (private repo `ShrenikMehar/gitatech-kit`):
   - If `$GT` is set or `~/gitatech-kit/lib/episode.py` exists, use that folder and run `git -C <kit> pull --ff-only`
     (Claude Code on his laptop, or a workspace that kept it).
   - Otherwise `git clone https://github.com/ShrenikMehar/gitatech-kit ~/gitatech-kit`. In claude.ai, attach the repo
     first with the add-repo tool (read access), then clone.
   - If the repo can't be reached: use an attached `gitatech-kit.zip`, or, if his computer is connected, ask in one
     line whether to look for it in Downloads; otherwise ask him in one line to connect GitHub or attach the zip.
2. **Read `<kit>/skill/SKILL.md` in full and follow it** as this skill's instructions for the rest of the session.
   Its section 0 (getting the kit) is already done. Read it after the pull, never from memory of an older version.
3. If neither the repo nor a zip is available yet, you can still discuss topics, beats and dialogue with him while
   waiting, using what he asks for; don't build anything until the kit and its `skill/SKILL.md` are loaded.
